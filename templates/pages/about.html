About ScamShield

Final Year B.Tech Computer Science & Engineering Project

ScamShield is a full-stack cybersecurity web application designed to protect internet users from digital scams, job fraud, phishing attempts, banking impersonation, and deceptive URLs.

Key Technical Innovations
  • Contextual Weighted Rule Engine: Multi-factor rule evaluation preventing false alarms on isolated keywords.
  • URL Structural Inspector: Identifies raw IP hosts, typosquatting brand variations, high-risk TLDs, and URL shorteners.
  • Transparent Risk Meter: Maps detection scores into Low, Moderate, and High Risk indicators with safe next actions.
  • Dual Database Support: Operates seamlessly on SQLite for local zero-config testing with instant toggle to MySQL production schema.
Technology Stack
Python 3.13 Django 6.1 Django REST Framework MySQL / SQLite Bootstrap 5 Chart.js
